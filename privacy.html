Политика конфиденциальности приложения «Академ»

Дата редакции: 9 октября 2026. Приложение «Академ» (ru.akadem.app) — расписание, задачи и напоминания. Оператор: Шеин Юрий Отариевич, e-mail для связи: akadem.support@gmail.com.

Что хранится на вашем телефоне

Расписание, задачи, настройки, монеты и образы питомца хранятся только на устройстве. Приложение не использует рекламу и аналитику и не запрашивает аппаратные идентификаторы.

Что отправляется на сервер

Только при наличии интернета и только это: случайный ID, созданный приложением при первом запуске (не связан с телефоном и аккаунтами); ник, если вы сами его ввели (необязательно); версия приложения; число монет и список образов; время последнего обращения. Также приложение скачивает общее расписание — без передачи ваших данных.

Зачем

Чтобы доставлять обновления расписания и выдавать подарки (монеты, образы) конкретному пользователю по нику или коду. Данные не продаются и не передаются третьим лицам, не используются для рекламы.

Где хранится

Сервер работает на платформе Cloudflare (Cloudflare, Inc.), серверы могут находиться за пределами РФ. Общее расписание и список подарков публикуются также в открытом репозитории на GitHub (GitHub, Inc.) и раздаются через сеть доставки jsDelivr; эти сервисы, как и любой сайт, видят IP-адрес устройства при скачивании файла.

Файл подарков

Если сервер недоступен, приложение читает общий публичный файл подарков. В нём нет вашего ID и нет самих кодов, только необратимые хеши (контрольные суммы): приложение сверяет их у себя на устройстве. Файл не содержит ников и других сведений о вас.

Срок хранения и удаление

Данные хранятся, пока вы пользуетесь приложением. Чтобы удалить свои данные, напишите на akadem.support@gmail.com, указав ID (он виден администратору; ник можно очистить в «Инфо → Ник»). Приложение без интернета работает как раньше, отправка данных при этом не происходит.

Дети

Приложение не предназначено для сбора данных детей младше 14 лет; ввод ника необязателен.
